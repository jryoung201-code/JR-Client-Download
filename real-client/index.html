Install

  1. Install Fabric and Fabric API for your Minecraft version.
  2. Put one matching Real Client JAR in your instance’s mods folder. If you already use Cape Workshop, replace its JAR with Real Client.
  3. Join a world and press Right Alt to open Real Client.
